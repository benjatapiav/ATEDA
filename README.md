# Manual descriptivo: 

# Desarrollo del proyecto ATEDA
- " Sistema de alerta temprana para la identificación de estudiantes con posiboes dificultades del aprendizaje "

# Introducción
- Este manual pretende describir el desarrollo completo del proyecto ATEDA en tiempo y forma. Se presenta la idea central que impulsa su posterior construcción, las tecnologías consideradas por experiencia y las modalidades de trabajo contempladas en su uso correcto.

# Objetivo central:
- Crear una aplicacion web interna que centralice antecedentes escolares, procese la información, encuentre patrones y genere alertas que ayuden a profesionales de la psicopedagogía a identificar de forma temprana a estudiantes con posibles dificultades del aprendizaje.

# Integrantes
Por desición propia no cuento con un equipo, por lo que todo será diseñado, desarrollado, testeado y aplicado por mí:
- Benjamin Tapia

# Metodología de Trabajo
Usaré una metodología ágil iterativa incremental. El proyecto se divide mediante una EDT en pequeños entregables y paquetes de trabjo. Cada paquete corresponde a nuevas funcionalidades revisadas y provadas. Se construye, se revisa, se prueba y se implementa, el proceso se repite.
