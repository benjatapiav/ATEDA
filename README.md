# Manual descriptivo: 
Desarrollo del proyecto # ATEDA #
- " Sistema de alerta temprana para la identificación de estudiantes con posiboes dificultades del aprendizaje "

Objetivo central:
- Crear una aplicacion web interna que centralice antecedentes escolares, procese la información, encuentre patrones y genere alertas que ayuden a profesionales de la psicopedagogía a identificar de forma temprana a estudiantes con posibles dificultades del aprendizaje.
